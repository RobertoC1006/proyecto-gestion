Herramienta: generación de imágenes integrada, sin CLI. Referencia visual del usuario: codex-clipboard-455de3c6-cca3-4878-b6c3-b34ca0b23ad6.png.

## Instrucciones comunes

Use case: ui-mockup. Generate a polished high-fidelity desktop application design board for CampusITSM, a university IT service desk, using the attached image ONLY as the visual style reference, NOT as an edit target. Follow its appearance closely: very pale cool gray #F5F6FA background, white slim 208px left sidebar, white top bar with search, notification bell, round initials avatar, deep navy #10182F text, vivid university green #009F60 primary buttons, dark green #075B43, pale mint #E2FAEE panels and circular line-icon backgrounds, orange warnings, red P1 badges, orange P2, gold P3, slate P4, subtle cool-gray borders and soft shadows, rounded rectangular cards with 12px radius, clean Inter-like sans-serif. Airy real product layout, thin outline icons, small mint laptop illustration only where appropriate. Brand top left a small green geometric mark and 'CampusITSM', caption 'Universidad Privada Tallán'. Do not use the UTP wordmark: this is the fictional institution in the project. No dark theme, no photos, no perspective, no physical devices, no decorative backgrounds. All UI copy in natural Spanish, crisp readable text. This is a conceptual desktop prototype with sample data. Each authenticated screen has a small 'Datos de demostración' chip. Realistic UI, not an infographic.

CANVAS AND COMPOSITION: one large landscape 3072x2048 image at highest possible resolution, exactly FOUR complete application screenshots arranged in a strict equal 2x2 grid. Each quadrant is a distinct full desktop screen, no cropping, each has its own full sidebar/topbar except public screens and login. Outer gutter 28px, inner gutters 28px, neutral pale-gray board background. A slim label ABOVE each screenshot gives its exact screen number and title, outside the app. Preserve every quadrant full and readable. No giant board title, no captions covering UI. Each screen should look like a 1440x900 desktop viewport scaled to fit. Avoid tiny paragraphs: prioritize large clear headings, controls and 3-4 table rows. Accurate spelling, no garbled labels. Keep same consistent visual system as reference across all quadrants and all boards.

ROLE RULES: student sees only own dashboard, incidencias, nueva incidencia, constancias, own calendar, notifications, no system-wide metrics or admin. Agent sees cola TI, tickets, historial and notifications. Supervisor sees demanda, alertas, reportes, modelos and authorized TI operations. Administrator sees calendario, configuración, usuarios, permisos, privacidad and auditoría. Display actual role as a noneditable label rather than an access-granting role selector. Hide 'Reiniciar demo'. No fake satisfaction score, no claims of real measured effectiveness. Main ticket T-2026-1048, Johan, Aula virtual – Acceso, exam at 10:30, reported10:02, urgency3 impact2 factor2 score12 P1. SLA P1 first response15min resolution2h; never30min. Model forecasts are separate from per-ticket priority. Signature shown only as 'Firma institucional · prototipo', never a claim of certified legal digital signature.
