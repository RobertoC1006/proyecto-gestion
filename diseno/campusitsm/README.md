# CampusITSM — Mockups de los tres casos de uso

Propuesta de diseño de escritorio, 6 de noviembre de 2026. Las imágenes son conceptos visuales con datos ilustrativos; no acreditan funcionalidades implementadas. Conservan la paleta verde y menta, tarjetas blancas, iconos y estructura de la referencia.

## Casos y recorrido

| Caso | Recorrido | Pantallas |
| --- | --- | --- |
| CU01 Incidencias | Acceso y consentimiento → inicio → reporte y evidencia → clasificación → seguimiento → cola priorizada → atención y resolución | P01–P08 |
| CU02 Constancias | Comprobar elegibilidad → solicitar → consultar PDF → verificar emisión pública válida o no válida | P09–P12 |
| CU03 Demanda y operación | Configurar calendario y reglas → administrar accesos → preparar datos → evaluar modelo → pronosticar → revisar alerta → preparar recursos → auditar | P13–P24 |

La preparación del CU03 antecede a la operación de los demás casos, y se mantiene durante su uso. La numeración corresponde al catálogo de pantallas, no obliga a una secuencia única de navegación.
